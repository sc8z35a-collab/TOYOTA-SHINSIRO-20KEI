# TOYOTA-SHINSIRO-20KEI

豊田・新城と周辺の森、36か所を紹介するスマートフォン専用ガイド。

## 画面と操作

- 縦画面：写真に案内を重ねる。横画面：写真と案内を左右に分ける。
- 左右スワイプで切り替え、写真タップで案内を隠し、上スワイプで詳細を開く。
- 地域・風景・移動方法による絞り込み、地名検索、端末内への保存。
- PCは案内のみ。タイトル画面・アプリ概要・ネオン表現なし。
- 全画面APIを起動時に試行し、ブラウザが拒否した場合は最初の操作で再試行。ユーザー操作を要求するブラウザの制約を回避することはできない。

## 写真と動き

- 写真を二層でクロスフェードし、表示後は緩やかに拡大。隣の写真は先読み。
- スワイプは指に追従し、一覧の写真は風景画面へ広がる。
- 写真タップで案内を隠す。ピンチで最大3倍、拡大中はドラッグで移動。
- 縦は写真全面と下部の案内、横は左の写真と右の生成りの案内。一覧は縦2列・横3列。
- 動くナビゲーション、順に現れる案内とカード、詳細シートの開閉。設定とOSの「動きを抑える」に対応。
- 線の背景は装飾用のベクター図形。実際の地形を示す地図ではない。

## 掲載情報

出発地は全スポット共通で、愛知県名古屋市天白区の原駅。住所と施設名を含む Google Maps 検索、原駅指定済みの経路リンクを用意。

予算は**車1台の往復燃料費の試算**で、現地費用とは別表示。道路データによる周辺までの距離、仮定したガソリン単価160～190円/L・燃費12～18km/Lを使用。上限側は距離に10%を加算。運賃、駐車料、入場料の未確認情報を数値で埋めていない。鉄道・バスは日時指定の経路検索で運賃を確認する。

混雑・訪日客の有無を保証するデータはない。静けさの記述とアクセス適性は編集上の目安。番地が公開されていない自然地には架空の番地を付けず、公式の所在地と地名を示す。

既存26景は2026年10月4日、追加10景は10月5日に自治体、観光協会、管理者の資料を確認。各案内の出典は `dist/data.js` とアプリの詳細に収録。写真は29か所分の実写で、転載用写真のない7か所には出典先への写真リンクを設けている。別の場所の写真や生成写真は使用しない。

追加10景：古宮城跡、寧比曽岳、愛知県民の森、伊熊神社の社叢、村積山、猿投七滝、おおだの森、黍生山・黍生城跡、吉祥山、くらがり渓谷。猿投七滝は周辺道の規制を明記し、車の経路・燃料費の終点を猿投神社付近としている。古宮城跡は地権者への配慮を含む見学条件を参照。

## オフライン

設定の「写真と案内を保存」で約12MBの静的ファイルを端末に保存。保存完了後は本文・写真・検索・絞り込み・保存機能が通信なしで動作する。外部の地図・出典はオンライン専用。OSやブラウザによる保存領域の削除はあり得る。

PWA manifest は `display: fullscreen`、縦横両対応。ホーム画面に追加可能。サービスワーカーはHTTPSまたはlocalhostで動作する。

## 将来のAndroid APK

現在の成果物はWeb/PWAであり、署名済みAPKは含まない。`dist/` は外部CDN・バックエンド依存のない配布用Webアセット。Capacitor等のAndroidコンテナに `webDir: 'dist'` として全アセットを同梱する構成に移行できる。WebViewでのサービスワーカーに依存せず、同梱アセットからオフライン起動する。地図は外部ブラウザ／Google Mapsへのリンクのまま維持する。

APK化時にはAndroid側の画面領域・システムバー設定、WebViewの外部URL処理、端末内保存、署名・実機試験が別途必要。

参考：<https://capacitorjs.com/docs/android> / <https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen>

## ファイル

- `dist/index.html` / `style.css` / `experience.css` / `app.js`：UIと操作
- `dist/motion.js`：写真遷移、一覧からの拡大、タッチ・ピンチ操作
- `dist/data.js`：36件の本文・住所・出典
- `dist/budgets.js`：道路距離、座標の根拠、燃料費の計算結果
- `dist/photos.js`：作者、原画像URL、ライセンス、撮影日
- `dist/sw.js` / `manifest.webmanifest`：オフライン・インストール
- `.openai/hosting.json`：Sites静的配信の設定

`npm run check` でJavaScript構文を検証。静的ファイルのためビルド処理は不要。通常のローカル環境では `npm run dev` で確認可能。配信ルートを `dist/` にする。相対URLなのでサブディレクトリ配信にも対応する。

GitHub Pages は `.github/workflows/deploy-pages.yml` が `main` の更新時に公開する。ルートの `index.html` が `dist/` に移動し、写真・フォント・PWAを含むアプリを表示する。ブランチからの配信でも同じURL構成になるよう、`.nojekyll` を配置する。Sites は引き続き `dist/` を配信ルートにする。

内容を更新した際は、`app.js` と `sw.js` のキャッシュ名を同時に更新する。
